# SpeakLoop design

Independent portfolio demonstration relevant to Everis; not their product or evidence of employment.

Local language practice app with at least three structured English/Spanish lessons, prompt selection, optional microphone recording/playback with denial handling and disposable recordings, honest self-rating, persisted practice history and progress. No fake AI pronunciation scores. Use Flutter web-compatible implementation and responsive phone/desktop layout; warm paper/coral/teal language notebook. Feature folders lessons/practice/progress; repository and controller separate from widgets.

Stack: Flutter + Dart, shared_preferences, record and audioplayers as needed.

Quality: clear names, small cohesive modules, no speculative abstractions, no private data or credentials. Synthetic fixtures. Accessible labeled controls, keyboard focus, responsive widths 390px and 1440px. Tests must cover domain invariants and API errors/persistence where applicable. README explains setup, architecture, limitations and AI-assisted implementation. Local demo only; public GitHub source publication authorized. No Sites hosting required for this repository deliverable.
